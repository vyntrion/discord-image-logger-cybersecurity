# Configuration

Configuration comes from three places, in this order of authority:

1. **Environment variables** — the strongest value; set in your shell or in
   `.env`.
2. **`.env`** *(optional)* — a `KEY=VALUE` file next to `main.py` that is
   loaded automatically at start-up (shell variables still win over it).
3. **`config.json`** — the authoritative file, edited directly or through
   `python3 setup.py`.

## Environment variables

Template: [`.env.example`](../.env.example) — copy it to `.env` and fill it in
locally.

| Variable | Purpose | Honoured today? |
|---|---|---|
| `DISCORD_TOKEN` | Bot token for an inbound bot module | Not used — this tree has no bot module (integration is webhook-outbound) |
| `WEBHOOK_URL` | Destination Discord webhook | ✅ — alias of `IMAGE_LOGGER_WEBHOOK` |
| `TUNNEL_URL` | Fixed tunnel URL to advertise instead of launching one | ✅ — `run.py` skips provider launch and self-tests the URL |
| `LOG_LEVEL` | Console verbosity: `DEBUG` · `INFO` · `WARN` · `ERROR` | ✅ |
| `DATA_RETENTION_DAYS` | Age after which events are deleted | ✅ — pruned at boot and hourly; `0` disables |
| `MAX_IMAGE_SIZE_MB` | Largest accepted body / preview image | ✅ — over-limit requests get `413` |
| `IMAGE_LOGGER_WEBHOOK` | Project-specific webhook override | ✅ |
| `NGROK_AUTHTOKEN` | ngrok credential (or `config.json` → `ngrokAuthtoken`) | ✅ |

Runtime overrides actually read by the code:

```bash
export IMAGE_LOGGER_WEBHOOK="https://discord.com/api/webhooks/<id>/<secret>"
export NGROK_AUTHTOKEN="<your-token>"          # only if you use ngrok
python3 run.py
```

> Rules: put real values in `.env` (git-ignored) or your shell — never in
> documentation, issues, screenshots, or commits.

## `config.json` reference

| Key | Type | Purpose |
|---|---|---|
| `webhook` | string | Discord webhook URL; `IMAGE_LOGGER_WEBHOOK` overrides it |
| `host` | string | Bind address — keep `127.0.0.1` |
| `port` | int | Local port; the launcher auto-increments if busy |
| `image` | string | Image URL shown to visitors and served to link-preview crawlers |
| `imageArgument` | bool | Allow `?url=<base64>` to select a per-link image |
| `username` | string | Outbound embed display name |
| `color` | int | Embed colour as an integer |
| `preview` | enum | `image` (real bytes, embed renders) · `loading` (tiny placeholder) · `redirect` (302) |
| `linkAlerts` | bool | Emit an event when the link is unfurled in chat |
| `accurateLocation` | bool | **Off by default.** Enables a browser location prompt — the visitor is asked, not silently tracked |
| `message` | string | Custom page text with `{ip}`, `{city}`, `{browser}` placeholders |
| `redirect` | object | Optional redirect target for visitors |
| `vpnCheck` / `antiBot` | int | Alert throttling for datacenter/VPN traffic |
| `dashboard.enabled` | bool | Serve the dashboard |
| `dashboard.path` | string | Dashboard route (default `/dashboard`) |
| `dashboard.token` | string | Required query token for `/dashboard`, `/events`, `/api/logs`, `/api/link`; `""` disables auth (**do not** do that publicly) |
| `tunnel` | enum | `auto` · `cloudflared` · `pinggy` · `ssh` · `serveo` · `ngrok` · `none` |
| `tunnelUrl` | string | Optional fixed public URL to advertise instead of launching a tunnel (`TUNNEL_URL` overrides it) |
| `ngrokAuthtoken` | string | ngrok credential (prefer `NGROK_AUTHTOKEN`) |
| `logFile` | string | JSONL archive path (default `logs/hits.jsonl`) |
| `dataRetentionDays` | int | Archive entries older than this are deleted at boot and hourly (default `7`, `0` = keep forever) |
| `maxImageSizeMb` | int | Request-body and preview-fetch cap in megabytes (default `10`) |
| `logLevel` | string | Console verbosity `DEBUG` · `INFO` · `WARN` · `ERROR` (default `INFO`) |
| `blacklistedIPs` | list | Prefixes excluded from alerting |

## Recommended baseline for a lab

```json
{
  "host": "127.0.0.1",
  "accurateLocation": false,
  "preview": "image",
  "vpnCheck": 1,
  "dashboard": { "enabled": true, "token": "<auto-generated>" },
  "tunnel": "auto",
  "logFile": "logs/hits.jsonl",
  "dataRetentionDays": 7,
  "maxImageSizeMb": 10,
  "logLevel": "INFO"
}
```

- **`host: 127.0.0.1`** — nothing listens on your LAN; the tunnel is the only
  way in.
- **`accurateLocation: false`** — avoid the permission prompt unless the
  exercise specifically needs precise coordinates *and* the participant has
  consented.
- **Non-empty `dashboard.token`** — otherwise anyone with the URL can read
  collected events.

## Precedence

```text
shell environment  >  .env  >  config.json  >  built-in default
```

A value already exported in your shell is never overwritten by the `.env`
file, and the documented overrides (`IMAGE_LOGGER_WEBHOOK`, `TUNNEL_URL`,
`LOG_LEVEL`, `DATA_RETENTION_DAYS`, `MAX_IMAGE_SIZE_MB`, `NGROK_AUTHTOKEN`)
always beat `config.json`.

## Validation

`setup.py` validates before saving:

- webhook → read-only API call; reports `✓ OK → #channel`, or `404` if revoked
- image → fetches the first bytes and confirms an image content type

Re-run it any time; it round-trips your existing values.
